# Cart To Camera Stories

I'm creating a UGC creator automation app that reviews unisex products from Amazon or Flipkart. The UGC creator reviews the product and explains them from a POV perspective with no face included, using generated scenes. Build the web app dashboard. Make sure I can connect my Instagram account easily, input Amazon/Flipkart products, generate scripts and POV video reviews, and post or schedule them to Instagram.
